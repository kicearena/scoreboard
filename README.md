# @kicearena/scoreboard

Controlled scoreboard rows, cells, controls and reveal presentation.

Private ESM package. Install with a GitHub Packages read credential in `NODE_AUTH_TOKEN`.

```sh
bun install --frozen-lockfile
bun run check
bun run test
bun run build
```

Release by tagging a verified commit `v0.1.0`. The tag workflow checks, builds and publishes the package. The consumer pins the exact version.
